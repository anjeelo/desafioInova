# Portfólio Pessoal

Projeto desenvolvido para apresentar meu perfil profissional, projetos e certificados.

## Sobre

Sou estudante de Sistemas de Informação no IFMA e tenho interesse nas áreas de desenvolvimento web e análise de dados. Este portfólio reúne alguns trabalhos, projetos e certificações obtidos durante minha trajetória acadêmica e profissional.

## Tecnologias Utilizadas

- HTML5
- CSS3
- Font Awesome

## Estrutura do Projeto

```
├── index.html
├── sobre.html
├── projetos.html
├── certificados.html
├── css
│   └── style.css
└── img
    ├── backgroundPC.png
    ├── backgroundMOBILE.png
    └── fotoPerfil.jpg
```

## Funcionalidades

- Página inicial com navegação entre as seções
- Página de apresentação pessoal
- Exibição de projetos desenvolvidos
- Listagem de certificados
- Links para GitHub e LinkedIn
- Layout responsivo para desktop e dispositivos móveis

## Responsividade

O projeto utiliza imagens de fundo diferentes para desktop e dispositivos móveis, proporcionando melhor adaptação a diferentes tamanhos de tela.

## Como Executar

1. Faça o download ou clone o repositório.
2. Abra o arquivo `index.html` em qualquer navegador.
